# Buildings (`building`)

Buildings in common/buildings.txt. Read-only.

- **Files:** `common/buildings.txt`
- **Layout:** one file with a block per record
- **Identifier:** the block key
- **Editing:** read-only (feeds pickers and catalogues)

## Fields

| Key | Type | Default | Required | Description |
|---|---|---|---|---|
| `max_level` | integer | — | no | Maximum level |

## Text keys

- `{id}` in localisation/00_<prefix>_buildings.csv
