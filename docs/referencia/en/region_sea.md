# Sea regions (`region_sea`)

Sea regions in map/region_sea.txt, shaped like the land ones. The game does not require a sea province to be in one.

- **Files:** `map/region_sea.txt`
- **Layout:** one file with a block per record
- **Identifier:** the block key
- **Editing:** read-only (feeds pickers and catalogues)
