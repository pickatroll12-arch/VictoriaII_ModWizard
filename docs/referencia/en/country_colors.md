# Uniform colours (`country_colors`)

common/country_colors.txt: three uniform colours per TAG. They are optional (147 of 271 vanilla countries have them).

- **Files:** `common/country_colors.txt`
- **Layout:** one file with a block per record
- **Identifier:** the block key
- **Editing:** created, duplicated and deleted from the Studio
- **Section:** `nations:countries`

## Fields

| Key | Type | Default | Required | Description |
|---|---|---|---|---|
| `color1` | RGB colour { r g b } from 0 to 255 | — | no | Colour 1 |
| `color2` | RGB colour { r g b } from 0 to 255 | — | no | Colour 2 |
| `color3` | RGB colour { r g b } from 0 to 255 | — | no | Colour 3 |

## Text keys

This schema creates no text keys.
