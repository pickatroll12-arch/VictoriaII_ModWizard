# Technologies (`technology`)

Technologies in technologies/*.txt. Read-only: they feed the pickers.

- **Files:** `technologies/*.txt`
- **Layout:** blocks at the root of each file
- **Identifier:** the block key
- **Editing:** read-only (feeds pickers and catalogues)

## Fields

| Key | Type | Default | Required | Description |
|---|---|---|---|---|
| `area` | word | — | no | Area |
| `year` | integer | — | no | Year |

## Text keys

- `{id}` in localisation/00_<prefix>_technologies.csv
