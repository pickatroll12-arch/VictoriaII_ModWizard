# Country registry (`country_registry`)

common/countries.txt: one TAG = "countries/<File>.txt" line per country. New TAGs go before dynamic_tags (and the comments right above it); after it, the game treats them as dynamic dominions.

- **Files:** `?`
- **Layout:** Registry
- **Identifier:** the block key
- **Editing:** read-only (feeds pickers and catalogues)

|---|---|---|---|---|

## Text keys

- `{id}` in localisation/00_<prefix>_countries.csv
- `{id}_ADJ` in localisation/00_<prefix>_countries.csv
