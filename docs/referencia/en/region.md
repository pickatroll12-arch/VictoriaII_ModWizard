# Regions (`region`)

Regions (states) in map/region.txt: each one is the list of its provinces. Every land province must be in one region, and only one.

- **Files:** `map/region.txt`
- **Layout:** one file with a block per record
- **Identifier:** the block key
- **Editing:** read-only (feeds pickers and catalogues)
