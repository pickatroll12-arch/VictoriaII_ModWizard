# Colores de uniforme (`country_colors`)

common/country_colors.txt: tres colores de uniforme por TAG. Son opcionales (en vanilla los tienen 147 de 271 países).

- **Archivos:** `common/country_colors.txt`
- **Disposición:** un archivo con un bloque por registro
- **Identificador:** la clave del bloque
- **Edición:** se crea, se duplica y se borra desde el Studio
- **Sección:** `nations:countries`

## Campos

| Clave | Tipo | Por defecto | Obligatorio | Descripción |
|---|---|---|---|---|
| `color1` | color RGB { r g b } de 0 a 255 | — | no | Color 1 |
| `color2` | color RGB { r g b } de 0 a 255 | — | no | Color 2 |
| `color3` | color RGB { r g b } de 0 a 255 | — | no | Color 3 |

## Claves de texto

Este esquema no crea claves de texto.
